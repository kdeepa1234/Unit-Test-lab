# Unit Testing Lab Using pytest

## Objective
To test calculator functions using automated unit tests.

## Technologies
- Python
- pytest
- Git
- GitHub

## Execution
Install dependencies:

pip install -r requirements.txt

Run tests:

pytest -v

## Test Cases
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Division by zero

## Result
The calculator functions are validated using automated tests.
